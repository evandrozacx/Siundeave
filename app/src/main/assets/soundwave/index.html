📌 Como funciona a atualização automática:
  1. Suba o código: Envie o projeto para o seu GitHub pelo menu do AI Studio.
  2. Gere o APK: No menu do AI Studio, selecione Export APK com a nova versão (ex: v1.2.0).
  3. Crie uma Release: No seu GitHub, vá em Releases ➔ Draft a new release, defina a Tag (ex: v1.2.0) e anexe o arquivo .apk!
  4. Pronto: O Android precisa do arquivo .apk para instalar. Ao abrir o app, os usuários receberão o pop-up com 1 toque!
